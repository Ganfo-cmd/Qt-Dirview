# Dirview
Графическое приложение на Qt для просмотра файловой системы.
Проект является модификацией примера Qt `itemviews/dirview`.

## Новый функционал

- Стартовой директорией является домашняя директория текущего пользователя
- Отображение скрытых папок и файлов
- Фильтрация данных по именам папок и файлов
- Функция подсчета размера папок, учитывая физически расположенные в ней файлы

## Debian package
Выполнена дебианизация готового решения.

Для сборки используется:
```
dpkg-buildpackage -b
```
Готовые пакеты Debian доступны в разделе GitHub Releases.

## Debian patches

Оформление изменений относительно исходного кода. Изменения располагаются в
```
debian/patches/
```

## CI/CD

Настроен GitHub Actions, который автоматически:
- устанавливает зависимости;
- собирает Debian-пакет;
- сохраняет собранный пакет как Artifact.

GitHub Actions собирает пакет Debian в среде Ubuntu. В результате сгенерированные зависимости соответствуют Ubuntu (например, libqt5core5t64) и могут отличаться от названий пакетов в Astra Linux. 
Для тестирования в Astra Linux рекомендуется использовать локально собранный пакет .deb, расположенный в GitHub Releases.
